# Security policy

Thank you for helping keep this site and its visitors safe.

## Reporting a vulnerability

Please report privately. Do not open a public issue.

- **Preferred:** use GitHub's private vulnerability reporting on this repository (Security tab → "Report a vulnerability").
- **Email:** security@littlejotsofjoy.ca

Please include what you found, where, and steps to reproduce. We aim to acknowledge reports within 3 business days. We are a small family business and do not run a paid bug bounty, but we will credit you if you would like.

## Scope

- The website at littlejotsofjoy.ca and its redirects
- The code and configuration in this repository

Out of scope: third-party services we link to (for example payment or social media platforms). Please report those to the provider.

## Our commitments

The site is static and collects no personal data directly. Security headers, dependency updates and automated scanning are part of every change. See `docs/adr/` for the decisions behind this.
